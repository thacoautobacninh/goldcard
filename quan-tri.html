Quản lý thẻ GOLD PRIVILEGE

Sửa ưu đãi, thay ảnh thẻ. Chỉ ảnh hưởng đến trang của hạng thẻ này.

Cách cập nhật trang web
  1. Sửa nội dung bên dưới. Muốn đổi ảnh thẻ thì chọn ảnh mới ở mục Ảnh thẻ.
  2. Bấm Tải file uu-dai.json, và bấm tải ảnh nếu có đổi ảnh.
  3. Chép các file vừa tải vào thư mục website, chọn Ghi đè (Replace) file cũ.
  4. Kéo cả thư mục vào mục Deploys của project trên Netlify.
